# Testimonials from Spring 2025 Students

If you are taking this class next the best advice I can give is to actually try the tools on your own and not just watch what happens in class. You learn way more by messing up and fixing it than by getting it right the first time. Dont be afraid of the terminal or Git because you get comfortable with them everything else in programming gets easier. Also keep your files organized and commit your work often so you always have something to fall back on when things break. If something confuses you ask questions early instead of waiting until you are stuck. This class isnt just about learning one language or one project. It is about building skills that will help you with every class after this and even real jobs later on. So stay curious, keep practicing, and remember that struggling with code is normal and part of how you get better.
